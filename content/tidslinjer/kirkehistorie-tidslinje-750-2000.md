Denne tidslinjen fortsetter der [[tidslinjer/kirkefedrene-tidslinje]] slutter (ca. 750 e.Kr.) og dekker kristendommens utvikling frem til år 2000. Se også [[studieplaner/studievei-kirkehistorie]] for veiledet leserekkefølge.

---

## Karolingisk tid og tidlig middelalder (750–1000)

| År | Hendelse |
|----|----------|
| ca. 754 | Pippin IIIs gavebrev — grunnlaget for kirkestaten |
| 780–850 | **Karolingisk renessanse** — Karl den store (742–814) reformerer kirke og skole; klosterskoler og katedralskoler opprettes |
| 800 | Karl den store kronet til «romersk keiser» av pave Leo III juledag |
| ca. 820 | Benediktinerordenens regler gjøres obligatoriske i frankisk kirke |
| 863 | **Kyrillisk alfabet** — Kyrillos og Methodios misjonerer til slaverne |
| 910 | **Cluny-klosteret** grunnlegges — reformklosterbevegelse som fornyer munkelivet |
| ca. 988 | Vladimir av Kiev døper Russland — ortodoks kristendom spres østover |

## Høymiddelalder og schisma (1000–1200)

| År | Hendelse |
|----|----------|
| 1054 | **Det store schisma** — Roma og Konstantinopel ekskommuniserer hverandre; øst og vest skiller lag permanent |
| 1059 | Pavelig valgreform — kardinalkollegiet overtar pavevalget |
| 1073–1085 | **Gregor VII** — investiturstriden; kamp om hvem som utnevner biskoper |
| 1095 | **Pave Urban II** utlyser første korstog ved Clermont |
| 1099 | Jerusalem faller til korsfarerne |
| 1115 | **Bernhard av Clairvaux** grunnlegger Clairvaux; mystisk teologi og klosterreform |
| 1122 | Worms-konkordatet avslutter investiturstriden |
| ca. 1140 | **Gratians Dekret** — kanonisk rett kodifiseres |

## Skolastikk og tiggerordener (1200–1350)

| År | Hendelse |
|----|----------|
| 1209 | **Frans av Assisi** får godkjenning for sin orden — fransiskanerne |
| 1216 | **Dominikus** grunnlegger dominikanerordenen — preken og teologi |
| 1215 | **Fjerde Laterankonsil** — transsubstansiasjon formuleres; skriftemål påbudt |
| ca. 1225 | **Hildegard av Bingens** skrifter sirkulerer vidt |
| 1231 | Inkvisisjonen formelt etablert av pave Gregor IX |
| 1265–1274 | **Thomas Aquinas** skriver *Summa Theologiae* — skolastikkens høydepunkt |
| 1302 | **Unam Sanctam** — Bonifacius VIII hevder pavens overordnede myndighet over alle |

## Senmiddelalder og krise (1350–1500)

| År | Hendelse |
|----|----------|
| 1347–1351 | **Svartedauden** — rammer Europa; kirken mister autoritet |
| ca. 1370–1380 | **Mester Eckhart** og **Johannes Tauler** — rhinsk mystikk |
| ca. 1380 | **John Wycliffe** oversetter Bibelen til engelsk; kritiserer pavemakten |
| 1378–1417 | **Det store vestlige schisma** — to (siden tre) konkurrerende paver |
| 1414–1418 | **Konstanskonsilet** avslutter schismaet; Jan Hus brent som kjetter (1415) |
| ca. 1418 | **Thomas à Kempis** skriver *Kristi etterfølgelse* |
| 1453 | Konstantinopels fall til osmanene — bysantinsk kirke under press |
| ca. 1450 | **Gutenbergs trykkpresse** — Bibelen trykkes; informasjon demokratiseres |
| 1492 | Columbus — kristendom og kolonialisme begynner å flettes sammen |

## Reformasjonen (1500–1600)

| År | Hendelse |
|----|----------|
| 1516 | **Erasmus** utgir gresk NT (*Novum Instrumentum*) — filologisk grunnlag for reform |
| 1517 | **Luther** slår opp 95 teser i Wittenberg — avlat og pavemakt utfordres |
| 1519 | **Zwingli** begynner reformasjonen i Zürich |
| 1521 | Luther ekskommunisert; Riksdag i Worms — «Her står jeg» |
| 1525 | **Den radikale reformasjonen** — gjendøperbevegelsen starter i Zürich |
| 1534 | **Henrik VIII** bryter med Roma — **Den engelske reformasjonen** |
| 1536 | **Calvin** publiserer *Institutio Christianae Religionis* |
| 1545–1563 | **Tridentinerkonsilet** — katolsk motreformasjon; svarer på protestantismen |
| 1555 | **Augsburgfreden** — «cuius regio, eius religio»; religionskrigenes logikk |
| 1559 | **Den skotske reformasjonen** — John Knox og presbyterianisme |

---

## Konfesjonalisering og religionskrig (1600–1700)

| År | Hendelse |
|----|----------|
| 1610-tallet | **Arminianisme-striden** — fri vilje vs. Calvins predestinasjonslære |
| 1618–1648 | **Tredveårskrigen** — religionskrig i Europa; Westfalerfreden avslutter den |
| 1620 | **Pilgrimsfedre** til Amerika — puritansk kristendom i ny verden |
| ca. 1650 | **Puritanismen** på sitt høydepunkt i England; Oliver Cromwell |
| 1675 | **Spener** publiserer *Pia Desideria* — **pietismen** starter formelt |
| 1678 | **Bunyan** publiserer *Pilegrimsreisen* |

---

## Pietisme og opplysningstid (1700–1800)

| År | Hendelse |
|----|----------|
| ca. 1700 | **Zinzendorf** og Hernhuterbevegelsen — global misjon fra Moravian-fellesskap |
| 1703–1791 | **John Wesley** — metodismen; åndelig fornyelse i England og Amerika |
| 1726–1742 | **Den første store vekkelsen** i Nord-Amerika — Jonathan Edwards, George Whitefield |
| 1740-tallet | **Haugianismen** — pietistisk folkelig vekkelse i Norge |
| 1784 | **Kant** publiserer *Hva er opplysning?* — fornuftens primat |
| 1799 | **Schleiermacher** publiserer *Om religion* — liberal protestantisme begynner |

---

## Modernitet og splittelse (1800–1900)

| År | Hendelse |
|----|----------|
| 1807 | **William Wilberforce** og avskaffelsen av slaveriet i Storbritannia |
| 1830-tallet | **Oxford-bevegelsen** — anglikansk høykirkelighet; Newman konverterer 1845 |
| 1845 | **Misjonsselskapene** vokser — global protestantisk misjon ekspanderer |
| 1854 | **Dogmet om Marias uplettede unnfangelse** — katolsk mariologi intensiveres |
| 1859 | **Darwin** publiserer *Artenes opprinnelse* — tro og vitenskap i spenning |
| 1870 | **Pavelig ufeilbarlighet** vedtas på Første Vatikankonsil |
| 1880-1900 | **Liberal teologi** dominerer protestantiske universiteter — Harnack, Ritschl |
| 1899 | **Adolf von Harnack** holder sine berømte forelesninger *Hva er kristendom?* |

## Det 20. århundret (1900–2000)

| År | Hendelse |
|----|----------|
| 1901 | **Pinsebevegelsen** starter i Topeka, Kansas — Parham og åndsdåp |
| 1906 | **Azusa Street-vekkelsen** i Los Angeles — Seymour; pinsebevegelsen globaliseres |
| 1910 | **Edinburghkonferansen** — moderne økumenisk bevegelse starter |
| 1918 | **Karl Barth** publiserer sin Romerbrev-kommentar — neo-ortodoksien bryter med liberalteologien |
| 1934 | **Barmen-erklæringen** — Bekjennelseskirken mot nazistaten; Barth og Bonhoeffer |
| 1945 | Bonhoeffer henrettet av nazistaten |
| 1948 | **Verdenkirkerådet** (WCC) grunnlegges i Amsterdam |
| 1950 | **Dogmet om Marias himmelfart** — Pius XII |
| 1962–1965 | **Andre Vatikankonsil** — katolsk modernisering; aggiornamento; Kirkens selvforståelse endres |
| 1966–1980 | **Karismatisk fornyelse** sprer seg i etablerte kirker |
| 1968 | **Medellin-konferansen** — latinamerikansk frigjøringsteologi; de fattiges kirke |
| 1974 | **Lausanne-erklæringen** — evangelikal konsensus om misjon og sosial handling |
| 1980-1990 | **Global Sør** — kristendommens tyngdepunkt forskyves til Afrika, Asia, Latin-Amerika |
| 1989 | Kommunismens fall — kirker i Øst-Europa trer fram igjen |
| 1994 | **Erklæringen om felles rettferdiggjørelseslære** — lutheranere og katolikker; undertegnet 1999 |
