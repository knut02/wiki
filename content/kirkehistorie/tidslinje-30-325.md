## 30–100: Urkirken

| År | Hendelse |
|---|---|
| ca. 30 | **Jesu korsfestelse og oppstandelse** — kristendommens startpunkt. Se [[kristologi/korsfestelsen]] og [[kristologi/jesus-sin-oppstandelse]] |
| ca. 30 | **Pinsedagen** — Ånden utgytes over disiplene; kirken oppstår som fellesskap. Se [[kirkehistorie/kristendommens-tilblivelse]] |
| ca. 30–50 | **Menigheter grunnlegges** i Jerusalem, Antiokia, Damaskus og videre. Se [[kirkehistorie/kristendommens-tilblivelse]] |
| ca. 35 | **Paulus omvender seg** på veien til Damaskus — den viktigste enkeltkonverteringen i kirkehistorien |
| ca. 46–57 | **Paulus' misjonsreiser** — evangeliet spres til Lille-Asia, Makedonia og Hellas. Se [[personer/paulus]] |
| ca. 49 | **Apostelmøtet i Jerusalem** (Apg 15) — avgjørende beslutning om at hedninger ikke trenger la seg omskjære |
| ca. 64–68 | **Neronsk forfølgelse** — første systematiske statsforfølgelse av kristne i Roma; Peter og Paulus trolig henrettet. Se [[kirkehistorie/martyriet-og-helgenkult]] |
| 66–70 | **Den jødiske krigen** — Jerusalem og tempelet ødelegges av romerne 70 e.Kr.; kristne flykter til Pella |
| ca. 70–100 | **NT-skriftene fullføres** — evangeliene og brevene sirkulerer og samles. Se [[lese-og-forstå-bibelen/bibelens-tilblivelse]] |
| ca. 95–96 | **Domitians forfølgelse** — Åpenbaringsboken trolig skrevet i denne konteksten. Se [[Bibelen - det Nye Testamentet/aapenbaringen]] |

## 100–150: De apostoliske fedrene

| År | Hendelse |
|---|---|
| ca. 95–110 | **Klemens av Roma, Ignatius av Antiokia, Polykarp** — de apostoliske fedrene skriver brev til menighetene. Se [[kirkehistorie/apostoliske-fedre]] |
| ca. 100–110 | **Didache** — den tidligste kristne instruksjonsboken om dåp, nattverd og gudstjeneste. Se [[kirkehistorie/didache]] |
| ca. 107 | **Ignatius av Antiokia martyrdød** — skriver sine berømte brev på vei til Roma; utvikler biskopsembetets teologi. Se [[kirkehistorie/embetsutvikling]] |
| ca. 112 | **Plinius den yngres brev til Trajan** — viktig utenforstående kilde om kristen gudstjenesteliv |
| ca. 155 | **Polykarp av Smyrna martyrdød** — ett av de tidligste detaljerte martyrdokumentene. Se [[kirkehistorie/martyriet-og-helgenkult]] |

## 150–200: Apologetene og den første teologien

| År | Hendelse |
|---|---|
| ca. 150–165 | **Justin Martyr** — den første store apologeten; forsvarer kristendommen overfor keisere. Se [[kirkehistorie/apostoliske-apologeter-og-hermas]] og [[personer/justin-martyr]] |
| ca. 140–160 | **Markions krise** — Markion forkaster GT og vil kutte kirken fra jødedommen; tvinger kirken til å tenke gjennom kanon. Se [[kirkehistorie/tidligkristent-mangfold]] |
| ca. 150–200 | **Gnostisismen blomstrer** — konkurrerende frelseslærer truer kirken innenfra. Se [[kirkehistorie/gnostisisme]] |
| ca. 160–225 | **Tertullian** — første store latinskspråklige teolog; mynter begrepet *trinitas*. Se [[kirkehistorie/tertullian]] |
| ca. 180 | **Irenaeus av Lyon skriver *Mot kjetterne*** — det første systematiske forsvar av kristen ortodoksi mot gnostisismen. Se [[kirkehistorie/irenaeus-av-lyon]] |
| ca. 180–200 | **Oldkirkens gudstjeneste tar form** — Ordet og nattverden som fast struktur. Se [[kirkehistorie/oldkirkens-gudstjeneste-struktur-og-praksis]] |

## 200–250: Aleksandrinsk teologi og forfølgelse

| År | Hendelse |
|---|---|
| ca. 185–254 | **Origenes** — den mest produktive teologen i oldkirken; leder for kateketskolen i Aleksandria. Se [[kirkehistorie/klemens-av-alexandria-og-origen]] |
| ca. 200–215 | **Klemens av Aleksandria** — integrerer gresk filosofi og kristen tro. Se [[kirkehistorie/klemens-av-alexandria-og-origen]] |
| ca. 202–203 | **Septimius Severus' forfølgelse** — særlig hardt rammet Egypt og Nord-Afrika; Perpetua og Felicitas martyrdøde. Se [[personer/perpetua]] |
| ca. 200–220 | **Hippolytus av Roma** — monarkhianisme-striden; liturgi og kirkedisiplin. Se [[kirkehistorie/hippolytus-og-gnostisismens-mangfold]] |
| ca. 249–251 | **Decisk forfølgelse** — første keiserlige dekret om at alle innbyggere skal ofre til de romerske gudene; massiv krise for kirken. Se [[kirkehistorie/martyriet-og-helgenkult]] |
| ca. 250–258 | **Cyprian av Karthago** — biskop og martyr; utvikler lære om kirken og biskopsembetet. Se [[kirkehistorie/cyprian-av-karthago]] |
| ca. 250–258 | **Novatianiststriden** — strid om behandling av de frafalne etter Decisk forfølgelse. Se [[kirkehistorie/novatianiststriden]] |

## 260–300: Pusterom og ny forfølgelse

| År | Hendelse |
|---|---|
| ca. 260–303 | **Pusterommet under Galliensediktet** — 40 år uten forfølgelse; kirken vokser og bygger; monastisismen begynner. Se [[kirkehistorie/pusterommet-260-303]] |
| ca. 270 | **Antonius den store trekker seg ut i ørkenen** — begynnelsen på det egyptiske eremittlivet. Se [[kirkehistorie/askese-i-oldkirken]] og [[personer/antonius-den-store]] |
| 303–311 | **Diokletians store forfølgelse** — den mest systematiske forfølgelsen; kirker rives, skrifter brennes. Se [[kirkehistorie/diokletians-forfølgelse]] |
| 311 | **Gallierius' toleranseedikt** — forfølgelsen avsluttes; kristne får lov til å samles igjen. Se [[kirkehistorie/diokletians-forfølgelse]] |

## 312–325: Den konstantinske vendingen og Nikea

| År | Hendelse |
|---|---|
| 312 | **Konstantin seirer ved Milviske bro** — tilskriver seieren den kristne Gud; kristendommen begynner å bli favorisert. Se [[kirkehistorie/den-konstantinske-vendingen]] |
| 313 | **Milanosediktet** — Konstantin og Licinius erklærer religionsfrihet i imperiet; kristne kan eie eiendom og bygge kirker |
| ca. 305–320 | **Donatiststriden** — strid om sakramentenes gyldighet ved uredige prester; Augustins svar blir normativt. Se [[kirkehistorie/donatiststriden]] |
| ca. 318 | **Arianiststriden begynner** — Arius fra Aleksandria hevder at Sønnen er skapt, ikke evig. Se [[kirkehistorie/arianismen]] |
| 325 | **Nikea-konsilet** — det første økoumeniske konsilet; vedtar at Sønnen er «av samme vesen som Faderen» (*homoousios*); avviser arianismen. Se [[kirkehistorie/nikea-konsilet]] og [[kirkehistorie/kristologi-frem-til-nikea]] |
